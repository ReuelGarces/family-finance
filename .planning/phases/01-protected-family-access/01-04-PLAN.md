**ASVS enforcement level:** L1

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Finance actor to mutation service | Client identifiers cannot substitute for the family resolved from active membership. |
| Reference validation to transaction write | All account/category/transfer references must be scoped inside the same transaction as the mutation. |
| Financial write to AuditLog | Audit insertion must commit or roll back with the financial event. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Tampering | Finance references and writes | high | mitigate | Query every target and reference with the trusted family predicate inside the existing transaction. |
| T-01-10 | Repudiation | Transaction, Transfer, and AuditLog | high | mitigate | Preserve the transaction-client audit append and prove rollback when audit persistence fails. |
| T-01-SC | Tampering | Package installs | high | mitigate | No package is added; any future dependency install must pass the GSD package-legitimacy gate first. |
</threat_model>
