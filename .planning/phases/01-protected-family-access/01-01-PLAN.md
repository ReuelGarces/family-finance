## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Login UI to Auth.js Credentials callback | User-controlled email and password enter credential parsing and verification. |
| Auth.js callback to PostgreSQL | Credential reads and lockout-counter writes must use the isolated test database in the test seam. |
| Test process to PostgreSQL | Environment configuration could otherwise point tests at an application or production database. |
